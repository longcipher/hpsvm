**2026-10-15-01-evm2-parity** is a ground-up architecture refactor modelled on the `evm2` project. It supersedes and absorbs the structural findings of 03 and 04; the performance gains planned in 02 (Arc-shared batch snapshot, opt-in diagnostics) are retained as inputs rather than re-planned. See [2026-10-15-01-evm2-parity/design.md](./2026-10-15-01-evm2-parity/design.md).

**2026-10-16-01-evm2-jit-parity** ports the tiering/caching machinery of evm2's `crates/jit/*` family. It re-opens the single item the parity spec declared blocked (the JIT pipeline) and shows that while the *compiler* stays agave's (`solana-sbpf`, already compiled in with `jit` on x86_64), everything around it — tiering policy, hot-threshold promotion, the resident entry store, background prewarm, stats, and the interpreted/compiled equivalence gate — is `hpsvm`-side code that does not exist today. See [2026-10-16-01-evm2-jit-parity/design.md](./2026-10-16-01-evm2-jit-parity/design.md).
